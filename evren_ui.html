POST /v1/audio/transcriptions
0 İstek
Model
qwen3-asr-1.7b
qwen/qwen3-asr-1.7b • Apache-2.0
Yerel Uç Nokta (8110)
http://127.0.0.1:8110/v1/audio/transcriptions
Alternatif: /evren/v1/audio/transcriptions
Yönlendirilen Upstream
https://evren-llmapi.ssyz.org.tr/v1/audio/transcriptions
Aktif kartın API anahtarıyla gider
Bağlam / Parametre
32K token • süre sınırı YOK
Ölçüldü: 218 sn / 9,6 MB sorunsuz • 2,3B (1,7B + ses kodlayıcı)
Sınırlar (bu kurulumda ölçüldü)
1 bayt – 100 MB • 12 biçim ✓
wav mp3 m4a aac flac ogg opus webm wma mp4 mkv 3gp • verbose_json ve diarized_json desteklenmez • srt zaman damgaları gerçek süreyle uyuşmuyor (109 sn'lik ses için 10:01 yazdı)
Ses kaydını metne çevirir (30 dil; Türkçe teyitli). Gövde multipart/form-data olmalıdır: model + file. Anahtar başlığı zorunlu değildir — istek, havuzdaki aktif kartın anahtarıyla upstream'e iletilir; sohbet oturumlarına (oturum atama) dokunulmaz.
Kota: Evren bu uçta token/kredi düşmez — yalnızca istek sayar (dakikada 1200). Günlük token kotanız ses istekleriyle azalmaz; süre (sn) yalnızca bu panelde yerel ölçüm olarak tutulur. verbose_json desteklenmez (upstream 400 döner).
Kod Örnekleri
curl 
curl http://127.0.0.1:8110/v1/audio/transcriptions ^
  -H "X-API-Key: aktif-kart" ^
  -F "model=qwen3-asr-1.7b" ^
  -F "file=@kayit.wav" ^
  -F "response_format=json"
Python 
import requests

with open("kayit.wav", "rb") as f:
    r = requests.post(
        "http://127.0.0.1:8110/v1/audio/transcriptions",
        headers={"X-API-Key": "aktif-kart"},
        files={"file": f},
        data={"model": "qwen3-asr-1.7b", "response_format": "json"},
        timeout=120,
    )
print(r.json()["text"])

🧭 Karar (Decision) — clef / laya

Modeller
clef • laya
clef: Cloudflare/clef, 27B (Qwen3.8-27B omurga), Apache-2.0 — görsel destekli
laya: yalnızca metin karar modeli
Yerel Uç Nokta
POST /v1/systemone
http://127.0.0.1:8110/v1/systemone • 8088'de de aynı uç • batch kapalı
Yönlendirilen Upstream
https://evren-llmapi.ssyz.org.tr/v1/systemone
Aktif kartın API anahtarıyla gider
Ne yapar?
Metin ÜRETMEZ
state + sorular → choice (seçenek), score (puan), noul (evet/hayır olasılığı) — tek geçişte olasılıklarıyla. output_tokens = 0.
Sınırlar (ölçüldü)
16.384 token • 4 görsel • 64 soru
Görsel başına 4 MiB, toplam 8 MiB; uzak URL reddedilir, video kapalı. Görsel karo karo sayılır: 32×32 px = 1 token → 760×760 ≈ 579, 1024×1024 ≈ 1.027, 1600×1600 ≈ 2.503 (ölçtüm). Pencere dolarsa metin sessizce kesilir: input_tokens = 16.384 ise kesilmiştir.
Yok sayılan alanlar
max_len • lang • min_confidence
clef bunları dikkate almaz; eşik koyacaksan yanıttaki probabilities değerini kullan (answer_confidence/low_confidence dönmez).
Mantığı: bir state (metin, e-posta, ticket ya da JSON belge) + questions nesnesi gönderirsin. Her soru type (choice|score|noul), instructions ve criteria taşır — choice'ta {anahtar: "açıklama"}, score'da sıralı etiket listesi, noul'da kriter gerekmez. clef'te images dizisine data:image/png|jpeg|webp;base64,… biçiminde en fazla 4 görsel eklenir (uzak URL yok). Yanıt: her soru için seçim/puan/olasılık + tüm seçeneklerin probabilities dağılımı.
Kod Örnekleri
curl 
curl http://127.0.0.1:8110/v1/systemone ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"clef\",\"state\":\"Faturamdan iki kez ucret cekildi.\",\"questions\":{\"birim\":{\"type\":\"choice\",\"instructions\":\"Hangi birim?\",\"criteria\":{\"fatura\":\"odeme, iade\",\"teknik\":\"hata\"}},\"acil\":{\"type\":\"noul\",\"instructions\":\"Acil mi?\"}}}"
Python 
import requests

r = requests.post(
    "http://127.0.0.1:8110/v1/systemone",
    json={
        "model": "clef",
        "state": "Faturamdan iki kez ucret cekildi.",
        "questions": {
            "birim": {"type": "choice", "instructions": "Hangi birim?",
                      "criteria": {"fatura": "odeme, iade", "teknik": "hata"}},
            "acil":  {"type": "noul", "instructions": "Acil mi?"},
        },
    },
    timeout=60,
)
a = r.json()["answers"]
print(a["birim"]["choice"], a["birim"]["probabilities"])
print("acil olasiligi:", a["acil"]["noul"])
